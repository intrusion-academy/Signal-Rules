# Code of Conduct

Issues, pull requests and discussions in this repository are for responders and Intrusion Academy staff to
build better detections together.

- Be respectful and constructive. Harassment, personal attacks and discriminatory language are not accepted.
- Keep to the subject of the issue or pull request.
- Never post data from a host you investigated, credentials, or details that identify a person or an organisation.
- Never post instructions for attacking systems. Rules detect; they do not teach attacks.

Intrusion Academy moderates this repository and may edit, hide or remove content, and block accounts, that do not
follow this code. To report a problem, contact Intrusion Academy through <https://intrusion.academy/signal>.
