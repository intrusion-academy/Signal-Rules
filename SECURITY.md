# Security

Signal's rules only read evidence; they cannot change a host. Still, report these **privately**, never in a public issue:

- a rule whose text or tests contain data from a real host (names, addresses, credentials);
- a rule that could make Signal fail or slow down badly on a host;
- anything in this repository that looks like it should not be public.

Report it through the [contact form](https://intrusion.academy/contact?topic=signal&subtopic=bug) on intrusion.academy,
and say it is about Signal Rules. You will get an answer, and the fix will be credited if you want.

A problem in Signal itself goes through the same form.
